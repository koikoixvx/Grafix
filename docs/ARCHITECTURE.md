# 🏗️ Arquitectura — Inkvill

## Módulos

| Archivo | Rol |
|---------|-----|
| `index.html` | Estructura base, 3 botones de acceso en footer del carrusel. |
| `app.js` | Núcleo: libros, páginas, capas, canvas. |
| `app-features.js` | Features adicionales (sin Modo Escritura ni placeholder de Esquemas). |
| `reference-tool.js` | Herramienta de referencia v5.3. |
| `page-gallery.js` | Galería de páginas v8.2. |
| `writer-notes.js` | Sistema de notas independiente. |
| `scenes-writer.js` | Módulo de Esquemas (Personajes, Escenarios, Plantillas). |
| `style.css` | Estilos globales y animaciones. |
